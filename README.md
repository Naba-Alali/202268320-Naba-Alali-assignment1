# Assignment 1 – Personal Portfolio Website

## Project Description
This project is a responsive personal portfolio website developed as part of Assignment 1.
The goal of this assignment is to apply foundational web development skills using HTML, CSS, and JavaScript, while also integrating AI-assisted tools responsibly.

The website introduces my background as a Software Engineering student and showcases selected academic projects.

## Objectives
-Practice structuring a webpage using HTML5
-Apply styling and layout techniques using CSS3
-Implement interactivity using JavaScript
-Create a responsive design that works on desktop, tablet, and mobile devices
-Use AI tools responsibly and document the learning process

## Features
.About Section
  -Short professional introduction
  -Creative tagline
  -Profile information card

.Projects Section
  -Two academic course projects:
    -Horse Racing Database System
    -Club Zone Platform
  -Project images
  -“Details” button that opens a modal with additional project information

.Contact Section
  -Contact form with:
    -Name field
    -Email field
    -Message field
  -Client-side form validation using JavaScript
  -User-friendly error and success messages
  -No backend required

.Interactivity
  -Light/Dark theme toggle (stored in localStorage)
  -Dynamic greeting based on time of day
  -Modal popup for project details
  -Form validation feedback

.Responsive Design
  -Implemented using CSS Grid and Flexbox
  -Media queries for tablet and mobile screens
  -Layout tested using browser resizing and DevTools


## Technologies used
