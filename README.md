# Assignment 1 – Personal Portfolio Website

## Project Description
A simple responsive personal portfolio website built using HTML, CSS, and JavaScript. The site includes About Me, Projects, and Contact sections, and basic interactivity.

## Features
- About Me section with a short introduction
- Projects section with two sample projects
- Contact form (no backend)
- Responsive design for desktop, tablet, and mobile
- JavaScript interactivity:
  - Dark/Light theme toggle
  - Greeting message based on time of day
  - Form validation with feedback messages

## Folder Structure
- `index.html` – Main webpage
- `css/styles.css` – Styling + responsive rules
- `js/script.js` – JavaScript features
- `assets/images/` – Images folder
- `docs/ai-usage-report.md` – AI tools usage report
- `docs/technical-documentation.md` – Technical documentation

## How to Run Locally
1. Download or clone the repository
2. Open `index.html` in any modern browser

## AI Use (Short Summary)
AI tools (ChatGPT) were used to help generate starter code, improve responsive design, and implement JavaScript features. Full details are in `docs/ai-usage-report.md`.
