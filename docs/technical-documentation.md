# Technical Documentation

## Project Overview
This project is a simple personal portfolio website built using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5 for structure
- CSS3 for styling and responsive design
- JavaScript for interactivity

## Folder Structure
- index.html: Main webpage
- css/styles.css: Website styles
- js/script.js: JavaScript functionality
- assets/images: Images used in the website
- docs/: Project documentation files

## How to Run the Project
1. Open the GitHub repository
2. Open the index.html file
3. View the website in a web browser

## Design Decisions
- Simple and clean layout
- Mobile-friendly responsive design
- Minimal JavaScript for basic interaction
